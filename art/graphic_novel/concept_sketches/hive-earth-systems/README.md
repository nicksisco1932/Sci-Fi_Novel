# Hive Earth Systems — Exploratory Render Index

Status: early ideation and adaptation reference only; not manuscript canon.

Each `v0.1` sheet presents the same subject at three nested scales: `MACRO` for the civilization or landscape system, `MESO` for the lived district or practice, and `MICRO` for the material object, interface, or bodily contact point. The filename and containing project path are printed on each image.

| Subject | Current sheet | Focus |
|---|---|---|
| Class differences | `class-differences-macro-meso-micro-v0.1.png` | One shared Hive machine; wealth expressed as silence, space, redundancy, and selective disconnection, poverty as density, queues, heat, repair, and visible dependence. |
| Mind link | `mind-link-macro-meso-micro-v0.1.png` | Physical planetary routing, district edge computation, and bounded personal neural hardware. |
| Blade technology | `blade-technology-macro-meso-micro-v0.1.png` | Blades as pervasive tools, maintainable object families, and inherited martial material culture. |
| Projectile technology | `scavenger-projectile-technology-macro-meso-micro-v0.1.png` | Rare off-grid weapons as dangerous, scarce, intergenerational craft rather than general armament. |
| Hive Earth | `hive-earth-scarred-recovery-macro-meso-micro-v0.1.png` | Existing Hive forms placed within a living Earth of altered biomes, repair landscapes, and uneven recovery. |

Future iterations should increment the suffix rather than overwrite an earlier render: `v0.2`, `v0.3`, then `v1.0` when a direction is deliberately selected. Canon status changes only through the manuscript and lore workflow, not by version number.
