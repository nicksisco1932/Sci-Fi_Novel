# Published editions

Only an edition expressly approved for distribution may be recorded under `hive-earth/<edition-id>/`. Retain the immutable publication file, frozen source manifest, integrity hashes, publication scope/license terms, and release date.

The 2026-10-07 v2 private beta is **not** a published edition. The earlier website/graphic-novel releases are separate historical production streams and are not silently relabeled as published prose.
