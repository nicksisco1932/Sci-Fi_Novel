# Proofs

Future copyedited/typeset proofs belong under `hive-earth/<edition-id>/`. Each proof must identify the exact source commit, include a complete inventory of all front/body/back matter, and record validation.

**No canonical or released prose manuscript is stored here.** Do not treat a proof as the active source; do not promote one to published without an explicit author decision.
